# 📋 Trial Plan Form

Página de formulário para seleção de planos, desenvolvida com HTML e CSS.

## 📸 Preview

![Preview do projeto](preview/preview-img.png)

## 🚀 Tecnologias

- HTML5
- CSS3

## 💻 Sobre o projeto

Este projeto consiste em uma página de seleção de planos, criada com o objetivo de praticar a construção e estilização de formulários utilizando HTML e CSS.

O projeto possui:

- Seleção entre diferentes planos;
- Campos de checkbox para aceite de termos;
- Layout responsivo;
- Estilização de elementos de formulário;
- Interface simples e organizada.
